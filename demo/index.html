      在有噪声的标注上，分清真提升和假提升Telling real gains from noise on imperfect labels

      最大的创新不是某一个技巧，而是一套能在噪声标注上判断“提升是不是真的”的评测方法，加上把模型压到线上可用速度的工程链路。

      The main contribution is not a single trick but an evaluation method that can tell whether a gain is real on noisy labels, plus an engineering path that brings the model to production speed.

      01

      打分代替生成 + 推理时先验调整Scoring instead of generation + prior adjustment

      对 4 个标签各算一次对数概率，再加上只在调参集上搜索的类别偏置。不用重训，宏 F1 +1.45 个百分点，效果等同于训练时重采样。

      Compute the log-probability of each of the 4 labels, then add class biases searched on the tune split only. No retraining: macro F1 +1.45 points, matching training-time resampling.

      02

      噪声感知的三种口径Three noise-aware views

      full（完整测试集）、clean（去掉有争议的 E/S 样本，争议集由不参与比较的模型委员会定义）、merged（E、S 合并为相关）。由此发现加数据、加商品文本的提升几乎都出现在标注本身模糊的样本上。

      full (whole test set), clean (disputed E/S rows removed, the disputed set defined by a committee of models not being compared) and merged (E and S as one “relevant” class). Gains from more data or richer product text turned out to live almost entirely on ambiguous labels.

      03

      模型当审计员，人工确认Models as auditors, humans confirm

      把多个模型一致反对原标注的样本抽出来盲评，组员人工复核后方向一致（E↔S 5.7% 对 6.8%，相关 / 搭配 / 无关 4.2% 对 4.1%）。一个低成本发现标注问题的流程。

      Rows that several models consistently dispute are blind-reviewed; teammates’ human review agrees in direction (E↔S 5.7% vs 6.8%, relevant / complement / irrelevant 4.2% vs 4.1%). A cheap way to surface label problems.

      04

      与偏置无关的排序指标Bias-invariant ranking metrics

      softmax 后的概率并不与偏置无关，所以直接用原始对数概率算 AUC / AP，把“模型变聪明了”和“模型只是换了倾向”区分开。

      Softmax probabilities are not invariant to the bias, so AUC / AP use raw log-probabilities. This separates “the model got smarter” from “the model only changed its prior”.

      05

      只看第一个不同的 token + 蒸馏 + vLLMFirst differing token + distillation + vLLM

      4 个标签在第一个不同的 token 之前完全相同，一次前向就能比较，吞吐约 4 倍；再蒸馏到 3B、用 vLLM，总共快 47 倍。还发现 4bit 上训练的适配器换到 bf16 推理，预测只有 86% 一致。

      The 4 labels are identical up to their first differing token, so one forward pass compares them (about 4× throughput); distilling to 3B on vLLM makes it 47× faster overall. An adapter trained on a 4-bit base agrees only 86% with itself when served in bf16.

      06

      事先写下判断标准Pre-registered criteria

      每个实验运行前写好“什么算成功”，用 3 个种子的范围是否重叠来判断。负结果（先推理再分类、自标注多任务）因此也有明确结论。

      Each run states in advance what counts as success, judged by whether three-seed ranges overlap. Negative results (reason-then-classify, self-labelled multitask) therefore also reach a clear verdict.

      结论Conclusions

      1. 稳定的收益只有三项：微调本身（0.384 → 0.535）、推理时先验调整（+1.45）、换成 14B 基座（+1.57）。Only three gains are stable: fine-tuning itself (0.384 → 0.535), inference-time prior adjustment (+1.45) and the 14B base model (+1.57).
      2. 标注质量是主要瓶颈：约 6% 的 E/S、约 4% 的相关 / 搭配 / 无关测试样本标注有争议，人工复核确认了方向。Label quality is the main bottleneck: about 6% of E/S and 4% of relevant / complement / irrelevant test rows are disputed, confirmed in direction by human review.
      3. 调类别比例约等于调先验，大部分可以用推理时的偏置代替。Rebalancing classes is roughly the same as shifting the prior, and is mostly replaceable by an inference-time bias.
      4. 可以落地：不伤通用能力，3B + vLLM 快 47 倍，方法能迁移到中文重排（MRR@10 0.256 → 0.346）。It is deployable: general ability intact, 3B + vLLM is 47× faster, and the method transfers to Chinese reranking (MRR@10 0.256 → 0.346).

      局限Limitations

      • 14B 的结论只覆盖 full / merged 宏 F1 与准确率；没有逐条打分，所以没有 clean 口径、bootstrap 和排序分析。The 14B claim covers full / merged macro F1 and accuracy only; without per-row scores there is no clean view, bootstrap or ranking analysis.
      • 意图、属性、改写多任务（D3）用 7B 自己标注，标注质量限制了效果。The intent / attribute / rewrite multitask (D3) was labelled by the 7B model itself, which limited it.
      • 标注审计每组只有 20–50 条样本；复核时讨论过少数边界案例，不是完全独立的第二位判断人。Each audit group has only 20–50 rows, and a few edge cases were discussed during review, so the reviewer is not fully independent.
      • 只用了 ESCI 的美国英文子集；中文实验每个 query 只标注了一个正例。Only the US-English part of ESCI is used; the Chinese set labels a single positive per query.
